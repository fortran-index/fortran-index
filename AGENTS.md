# AGENTS.md file for Fortran index

## High-level information

### Project overview

Fortran index is a community initiative that aims to improve the usefulness of Fortran-lang's package index for the Fortran community.

### Project team

- This project is being worked on by a volunteers from the Fortran community.

## Details

### Agent-specific resources

- The `.agents/` subdirectory contains agent-specific resources.
- The `.agents/skills` submodule contains skills that the RSE team often works with. Make use of the following skills in this project:
  - [fortitude](.agents/skills/skills/fortitude.md)
  - [ford](.agents/skills/skills/ford.md)

### Knowledge

- Notes on setup can be found in `knowledge/overview/Setup.md`.
- Notes on the work so far can be found in `knowledge/work/`.
- Notes on contributions so far can be found in `knowledge/contributions.md`.
- Notes on meetings between the project team and with collaborators can be found in `notes/meetings/`.
- Summary notes can be found in `knowledge/overview/`.
  - Start by reading these.

### Fortran-lang webpage submodule

- The Fortran-lang webpage is built using Sphinx.
- See the [quick start](#quick-start) section for instructions on setting up the environment and building the webpage.
- See [CONTRIBUTING.md](CONTRIBUTING.md) for information on contributing to Fortran-lang.

## Quick start

- Set up the Python environment my running `source setup.sh`
- Build the Fortran index and Fortran-lang websites by running `./build.sh`
